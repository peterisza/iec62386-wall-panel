This is a smart-home wall panel that is intended to be DALI-compatible when it's finished. It has sensors for temperature, humidity, air pressure, and CO2. Its front is customizable and user-swappable with up to 16 capacitive touch channels.

## Status / Important Notice

This project is a **prototype** and **not a consumer product**. It is under active development and may be incomplete, unstable, or non-compliant with relevant standards.

### DO NOT CONNECT TO A REAL DALI NETWORK (YET)

**Do not connect this device to any production / real DALI installation.**  
The current firmware is not DALI-compliant and is intended for development only. In its current state it will:
- transmit debug frames (e.g., 16-bit debug frames),
- respond incorrectly to forward frames (e.g., fixed/placeholder back frame behavior),
- cause unexpected bus behavior.
