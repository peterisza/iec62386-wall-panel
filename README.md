This is a smart-home wall panel that is intended to be DALI-compatible. It has sensors for temperature, humidity, air pressure, and CO2. Its front is customizable and user-swappable with up to 16 capacitive touch channels.

In the current state it only sends 16-bit debug frames, and always responds with the same back frame to every forward frame. So don't connect it to an actual DALI network yet.
